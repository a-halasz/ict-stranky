# ICT Pro – Web

Website for ICT Pro, a Czech IT training company. Built with plain HTML, CSS, and vanilla JS — no frameworks.

## Pages

- `index.html` — Main landing page
- `kurz-aicl.html` — Course page: Claude – AI jako pracovní nástroj (AICL)
- `kurz-clvc.html` — Course page: Claude AI – VIBE coding (CLVC)
- `podminky.html` — Podmínky užívání (Terms of use)

## Features

- Bilingual CZ/EN toggle
- Responsive layout with mobile hamburger menu
- Smooth scroll navigation
- Contact form

## Deployment

Hosted on GitHub Pages at `https://a-halasz.github.io/ict-stranky/`.
